# Retail Analytics Project — Overview

## Objective
Build an end-to-end retail analytics solution that demonstrates practical data analyst capabilities across SQL, Python, customer analytics, KPI design, and BI.

## Business problem
Retail management needs a unified view of sales, customers, products, stores, returns, loyalty, and campaign activity to improve revenue quality, customer retention, product decisions, and store performance.

## Analytical layers
1. Raw data ingestion
2. Data quality and cleaning
3. Relational data model
4. SQL KPI and diagnostic queries
5. Python feature engineering
6. RFM segmentation and CLV proxy
7. BI semantic layer
8. Business recommendations

## Key outputs
- Cleaned CSV datasets
- PostgreSQL schema
- SQL analytics query pack
- Python cleaning and KPI scripts
- RFM/CLV customer feature table
- BI dashboard specification
- Data dictionary
- Business requirements
